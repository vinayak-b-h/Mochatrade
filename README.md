# MochaTrade — Prototype

Three live surfaces from the Marketsphere Hackathon deck: a trader order ticket
(Velocity Ladder), a regulator dashboard (read-only harm/FX telemetry), and an
ops kill-switch console (market-scoped leverage halt).

Built with Next.js 14 (App Router) + TypeScript + Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy

Push to GitHub, then import the repo at https://vercel.com/new — no config
needed, Vercel auto-detects Next.js.
